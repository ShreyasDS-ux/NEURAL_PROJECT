# Customer Churn Prediction using Neural Networks

Predicts customer churn on a synthetic dataset of 100,000 customers.

## Models compared
- Logistic Regression
- Random Forest
- Neural Network (Keras/TensorFlow)

## Results
The neural network performed best: accuracy 0.76, ROC-AUC 0.80.

## Files
- `Neural_project.ipynb`: full analysis and model code
- `synthetic_customer_churn_100k.csv`: dataset
